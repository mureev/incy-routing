# Security

## Reporting

Report privately, with GitHub's **Report a vulnerability** button on this repository's *Security* tab, not in a
public issue.

## Scope

- Anything that lets a request read more than the published profiles: other files, the data directory, the
  environment.
- Anything that lets a build publish something the upstream lists did not say. That includes partial or gutted
  profiles getting past the gate.
- A wrong routing result is an issue, not a report.

## What to expect

This is a personal instance. There is no bounty and no promised response time. A fix, once there is one, is live
within minutes of reaching `master`.
